iOS vs web icon inventory

Side-by-side of every intentional icon mapping in the iOS follower (SliccIcons.swift, DockModel, LucideIcon) against the web equivalents (TOOL_ICONS / BASH_ICONS in wc-message-view.ts, lick KIND_ICON, dock rail). SF Symbols are rendered from the local macOS symbol set; Lucide icons hydrate from CDN.

13 weird 16 drift stale iOS leftovers matched

The weird ones (why this feels off)

  • Tea cup for ice cream — scoop_scoop, scoop-notify, and the unused cone messageSource map to cup.and.saucer.fill because SF Symbols has no cone. The dock/monitor already use the ported Lucide cone/bowl.
  • Mute = speaker, not bell — web mutes scoop notifications (bell-off); iOS shows an audio speaker slash.
  • list_scoops — web shows an ice-cream cone; iOS shows a bullet list.
  • Lick channel drift — fswatch, scoop-idle, scoop-wait pick different metaphors than the web lick card.
